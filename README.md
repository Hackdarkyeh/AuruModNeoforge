# AurumNeoForge

AurumNeoForge es un mod para Minecraft 1.21.1 desarrollado sobre NeoForge, que introduce una dimensión, estructuras, sistemas de almas, habilidades, energía y mecánicas avanzadas para jugadores y desarrolladores.

## Características principales

- **Nueva dimensión Aurum**: Incluye generación personalizada, eventos climáticos únicos (noche perpetua, luna púrpura, lluvia dorada), y biomas especiales.
- **Sistema de almas**: Cada jugador puede tener una única alma, con datos personalizados (tier, honor, peso máximo, habilidades). Las almas se gestionan mediante componentes de datos y se pueden modificar en la Soul Modification Table.
- **Habilidades de alma**: Las habilidades se almacenan y gestionan en objetos especiales, permitiendo personalización y progresión.
- **Energía y tecnología**: Implementa bloques y objetos como baterías, generadores, cubos de energía y sistemas de almacenamiento, con capacidades y transferencia de energía.
- **Estructuras avanzadas**: Generación de fortalezas y puentes dinámicos, con pools de plantillas y algoritmos de colocación.
- **Integración con Jade**: Proveedores de datos y componentes para mostrar información avanzada en la interfaz.
- **Tags personalizados**: Define tags para items, bloques y tipos de daño, facilitando la compatibilidad y la expansión.
- **Eventos y efectos**: Efectos como Aurum Blight, que afectan a jugadores y entidades, con lógica de daño, inmunidad y manipulación de armaduras.

## Estructura del proyecto

- `src/main/java/aurum/aurum/` contiene la lógica principal, sistemas de almas, items, estructuras, generación de mundo, integración y eventos.
- `src/main/resources/` incluye configuraciones, plantillas de estructuras, mixins y archivos de mod.
- `build.gradle` y archivos de configuración gestionan dependencias, mapeos y compilación.

## Para desarrolladores

- El mod está preparado como plantilla profesional, permitiendo clonar y expandir fácilmente.
- Utiliza mapeos oficiales de Mojang y NeoForge, asegurando compatibilidad y claridad.
- Incluye ejemplos de integración con Jade, generación de estructuras, y sistemas de datos avanzados.
